# 洲弹 · 云端采集数据

《三角洲行动》子弹交易行价格的**云端采集结果**，供本地桌面程序「洲弹」消费。

采集在 GitHub Actions 的服务器上跑，**与任何一台电脑是否开机无关**——每 30 分钟一轮，7×24 不间断。

---

## 为什么单独开一个仓库

| 原因 | 说明 |
|---|---|
| 免费额度 | 公开仓库的 Actions 分钟数不计量；private 仓库每月只有 2000 分钟，每 30 分钟一轮会顶到上限 |
| 数据无隐私 | 只有公开交易行的价格，不含账号、道具、身份信息 |
| 与主项目解耦 | 采集端和消费端各自独立，任一侧改版不会连累另一侧 |

## 目录

```
collect.py                     采集脚本（纯标准库，零依赖）
.github/workflows/collect.yml  GitHub Actions 定时任务
data/YYYY-MM-DD.jsonl          每 30 分钟一行快照（按北京时间分天）
hist/YYYY-MM-DD.json           当天最后一次的历史价快照（3/7/30 日）
```

## 数据结构

### `data/YYYY-MM-DD.jsonl`

每天一个文件，一行一次采样，追加写入：

```json
{"t":1793255291,"d":[[".45 ACP FMJ",3,431,386,461],[".50 AE JHP",3,484,324,484]]}
```

| 字段 | 含义 |
|---|---|
| `t` | 采集时刻，Unix 秒 |
| `d` | 数组，每项 `[名称, 等级, 现价, 今日最低价, 今日最高价]` |

用数组而不是对象：一行 85 条约 2.9 KB，对象写法要 3 倍体积。

### `hist/YYYY-MM-DD.json`

当天最后一次抓到的历史价位（该站现价已改为登录可见，但 3/7/30 日价仍公开）：

```json
{"t":1793255291,"o":{".45 ACP FMJ":{"p3":420,"p3p":2.6,"p7":410,"p7p":5.1,"p30":398,"p30p":8.3}}}
```

| 键 | 含义 |
|---|---|
| `p3` / `p3p` | 3 日前价格 / 相对涨幅 % |
| `p7` / `p7p` | 7 日前价格 / 相对涨幅 % |
| `p30` / `p30p` | 30 日前价格 / 相对涨幅 % |

## 数据从哪里来

| 源 | 提供 | 备注 |
|---|---|---|
| `deltaammo.com` | 现价、今日最低/最高价、等级 | 数据内嵌在服务端渲染的 HTML 中，免登录 |
| `orzice.com` | 3/7/30 日历史价 | 现价需登录，这里只取历史维度 |

## 已知边界

- **GitHub 定时器不保证准点**：`*/30` 只是「每半小时触发一次」，高峰期可能延迟几分钟到十几分钟，少数轮次会被跳过。做分时统计时按 `t` 的实际值聚合，不要假设整点整分。
- **公开仓库连续 60 天无提交会自动停用定时任务**：本仓库每轮都会提交数据，正常情况下不会触发。
- **单次失败不会污染数据**：现价抓不到时本轮不落盘，只保留历史价，并让 Actions 标红以便发现站点改版。
- **历史序列无法回补**：站点只提供「几日前价格」这类聚合值，真正的分时序列只能自采集，从启用之日开始累积。

## 许可证

数据来源于第三方公开站点，仅供个人研究参考，不含任何游戏内交易行为。
